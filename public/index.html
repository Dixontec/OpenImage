Conectar à Cloudflare

Suas chaves ficam só neste navegador e passam por este servidor local apenas para falar com a Cloudflare.

Como obter
  1. No painel da Cloudflare abra Workers AI e use Use REST API; o Account ID aparece ali.
  2. Clique em Create a Workers AI API Token (permissão Workers AI · Read/Edit).
  3. Opcional: adicione Account Analytics · Read ao token para sincronizar o consumo real de neurônios.
